# 03-愿景形态与楔子（可行切入点）

> 来源：swarm"检验 agent 招聘愿景"调研（2026-09 联网实证）。
> ⚠️ 2026-09-06 三路对抗复核后**修订**：本节"首选/次选"已被推翻重排，旧版本见文末"修订记录"。

## 一、愿景形态（你的设想 → 检验后）
- **招聘者侧**：跟 agent 对话 → 全面精准匹配 → 获取简历 → 跟进面试 → 自动管理企业候选人池
- **求职者侧**：agent 结合互联网痕迹（项目/作品）+ 本地文件 → 快速凝结简历 → 评估能力 → 辅助职业方向 → 精准匹配企业推荐 → agent 辅助提升方向

**检验结论**：双向平台的每个单点 2025-2026 已被巨头与重金玩家占道。**从零做"双向撮合"不可行**（鸡生蛋破不了、候选人数据护城河在存量平台手里）。→ **双向平台 = 远期叙事，不是起点。**

## 二、已在做"求职者侧/双向"的人（现实）
- LinkedIn Hiring Assistant（雇主侧主导）、Indeed Career Scout（求职者侧，免费）
- Jobright（$30/月，52 万用户）、LiftmyCV（自主求职）、Tsenta（YC，$100K MRR）
- OpenAI Jobs Platform（含求职者 agent + 认证）、Mercor（转 AI 数据供应商，中心化人才库）
- 国内：Boss"直闪闪"免费、智联"职悟空"未上线

## 三、可行窄楔子（三路对抗复核后 · 修正版）

### ⚠️ 已被推翻的旧首选：求职者侧"能力证据档案"
**2026-09 复核后判为不成立**：
- 稀缺 AI 人才（约 75% 被猎头挖走）不需要"找工作工具"——巨头全免费（Indeed Career Scout、智联职悟空已于 2026-07 上线、Boss DeepHire 2026-03 已开放免费求职者侧自动投递/面试），开源也已能做（JobKit=本地+GitHub→简历）
- "用户自持数据"是伪护城河：可移植=零切换成本、反网络效应、且已被开源
- 候选人"拿到 offer 才付费"结构性收不到：归因无法证明、有中国避讳
- 结论：**求职者侧空间已被填，候选人付费弱，弃**（原旧文本见文末修订记录）

### ✅ 修正后首选：向雇主/猎头收费的"AI 验证型猎头服务"
- **卖什么**：给中国 AI 工程师做"技术验证"，卖给**雇他们的雇主/猎头**——按成单收 **20-30% 寻访费 + 风险返还承诺**（人不行退钱/换人）
- **为何成立（复用你真实资产）**：顶级猎头背书、bole.hanxai.cn 已有雇主客户、你能亲自做技术评估（量化级验证，非生成）
- **保留"证据验证"想法**，只是**付费方从候选人换成雇主**——符合"付钱的该是承担风险的买方"第一性
- 本质 = 服务公司（B2B 高级寻访外包），不是平台/数据公司——别用平台叙事骗自己

### 数据校正（复核时重验）
- 原"AI 岗供需 3.2:1 / 美招聘 -19% / +88%"方向对但无法精确复现；中国 2026 实测按岗位类型是 **0.15–3.08 区间**，别当精确值
- Mercor 4TB 泄露 + 7 起集体诉讼（FCRA/BIPA，4 万人生物数据）**属实**，但它现在是模型厂数据商（$614M/90% 来自模型厂），不是求职产品

## 四、风险（诚实）
AI 正结构性消灭中初级白领/外包/标注岗 → **数量撮合型招聘是逆风行业**。
求职者侧对冲只在两处成立：**稀缺 AI 岗** 与 **迁移/再培训**——不是"帮人人找到工作"。
→ 愿景收窄为 **"只服务 AI 稀缺人才的求职者侧数据 agent"**：一人能先跑、再长成平台的可行版本。

## 五、总结
- **起点**：AI/技术稀缺人才的"能力证据档案"，出海/全球远程，本地优先、用户自持
- **收费**：向候选人（拿到面试/offer 后）或向猎头（成单提成）
- **终局叙事**：招聘者 agent + 求职者 agent 的双向 AI-native 平台

## 修订记录（2026-09-06 三路对抗复核）
**旧首选（已弃）**：求职者侧"能力证据档案"，候选人付费，主打出海/远程。
**弃因**：空间已被智联职悟空(2026-07上线)/Boss DeepHire(2026-03开放)填上；稀缺人才不付钱；用户自持数据=伪护城河；按 offer 向候选人收费结构性收不到。
**新首选**：向雇主/猎头收费的"AI 验证型猎头服务"（技术验证 + 20-30% 成单费 + 风险返还）。本质 = B2B 寻访外包服务公司，非平台。
