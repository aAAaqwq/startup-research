## 弧线

### 一、大愿景：做一个 AI-native 人才宇宙
招聘正被 AI 重写，但重写方向不是"更快匹配更多简历"，而是——伪造简历成本趋零，**"证明一个人真能干活"变贵、变稀缺**。愿景即由此而来：双向 AI-native 平台（招聘者 agent + 求职者 agent），求职者持"能力证据档案"绕过平台与猎头的简历游戏。这个"人才宇宙"只能当终局叙事，**不是起点**。

### 二、现实削减：求职者侧被巨头填满，候选人付费不成立
三路对抗复核逐层削掉愿景：
- **求职者侧已无空档**：Boss DeepHire（2026-03 求职端 agent 免费）、智联"职悟空"（2026-07 已上线）都在 C 端免费内置，海外 Indeed/OpenAI Jobs 同路；
- **稀缺人才不付钱**：约 75% 被猎头/内推被动挖走，能力报告用 GitHub 免费就能换到；
- **"向候选人按 offer 收费"结构性收不到**：归因无解、必被绕单；
- **"用户自持数据"是伪护城河**：可导出 = 零切换成本 = 攒不下撮合资产。

第一性反转（06）：**谁承担错付风险、谁有预算，谁才付钱——是雇主，不是候选人。**

### 三、实测戳穿：bole 6685 → 2，无自然客户
对现有产品 bole/稷衡智聘的一手实测（01）戳破最后一层自欺：它本质是**"单 Boss 账号桌面 RPA 爬虫 + 记账本"**——全库 6,685 条候选人仅产生 2 次约面（约面率 ≈0.03%）、NAS 归档已停 3 周、企业多为自建试点、几乎无自然客户，且 Boss 依赖 100% 脆弱 + 判赔 23 万诉讼红线。（2026-09-08 终裁更正：这批“雇主”多为自建试点/测试账号、几乎无自然客户，**非真实付费暖客户，不得当冷启动地基**——见 01 §四 与 `12-伪需求死刑审判与终裁.md`）它可迁移的是桌面执行/审计工程 + evidence 评分雏形，且其自身现金流与 Boss 诉讼红线须单独核验。

### 四、破局：AI 验证型猎头，雇主付费，用 bole 雇主当暖客户
由此只剩一种能收钱的活法：**AI 验证型猎头服务**——给中国 AI 工程师做技术验证，卖给雇他们的雇主/猎头，按成单收 20-30% + 风险返还（人不行退/换）。本质 = **B2B 寻访外包服务公司，不是平台**。冷启动不靠"我是社区成员"，靠 bole 现成的 5-6 家试点雇主 + 十余招聘者——同一批"要人 + 要判断"的人，用他们自己 6685→2 的失败漏斗当价值主张。

### 五、首单实验：唯一现在该做的事（09）
4 周内，从 bole 现有雇主里挑漏斗最惨的 1-2 家（次选猎头渠道），要真实出海 AI 岗，交付 2-3 名做过技术评估、敢签"证明不了能干活就退钱"的候选人。指标只认定金 / 真 JD / 进面；≥1 成单或续约推荐 = 继续，否则 pivot/kill。

### 六、终局方向：去中心化交付结果 → 人才宇宙
首单成立后，逐单攒**验证记录 / 口碑 / 撮合结果**——唯一随时间变贵、模型拿不走、巨头懒得做的资产。攒够那天，"人才宇宙"（双 agent + 可核验证明 + 雇主敢担保的结果交付）才从愿景长成真平台。今天离它只差一份 `09`。
