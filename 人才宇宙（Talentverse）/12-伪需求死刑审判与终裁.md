## 三、终裁判定与理由

基准（命题方自定）= "有无任何一条需求能用站得住的一手证据证明非伪？"
1. 出海雇主愿为独立验证付 20-30% → **零一手证据**
2. bole 老雇主痛在判断、愿为验证付费 → **一手证据反证**（自建试点）
3. 验证溢价 ΔP>0 可自证 → **结构上被锁死在不可测**
4. 该口径能合法收款 → **资格性违法**

四路无一主张 continue；各自保留的活路(B'/退费率自证/公司化+持牌)也只是**未被证伪的假设、无一手需求证据**。故按命题方判定标准，唯一诚实裁决 = **推倒重来**（非"修措辞"）：10 地基层已被仓库自身一手文件逐根打断，缺的是**待补的一手需求证据**，不是可修的说法。跑 09 = 拿 4 周验一个已被证伪的前提。

**推倒≠方向无价值**：拆的是"声明层"，保留"可再推导碎片"（见四）。

## 四、幸存资产 + 新推导起点

**保留资产（按可信度，前两项需再核验、不作自证）**：
1. **创始人作为"人"的信任杠杆**：真实技术评估判断力 + 顶级猎头背书关系 + 出海远程社区成员身份——唯一未被证伪、唯一能撬真实买方的东西（须以真实买方动作重新验证）。
2. **校正后的市场结构地图**（防重蹈）：20-30% 买全套寻访交付；验证是免费/百元级部件；卖方须境内持牌可签约可诉；担保须事实级且有资产支撑；产品线停"事实核验"侧。
3. **bole = 过渡 RPA 工具 + 触达渠道 + 工程底座**（仅当自身现金流与 Boss 诉讼红线单独核验可控，此点同样未证）。

**新推导起点（待验证假设，非自证）**：
> "在**境内持牌、可签约可诉**主体下，向**经真实付费史核验的已信任买方**（背书猎头境内主体/真实非自建 bole 老雇主），按成单收**行业锚价 20-30%**，交付'从已有候选人池验证出的可交付者 + 事实级担保 + 境内按约收款'；验证只作**获客佐证、不作价**。出海冷雇主与'验证独立 20-30% 溢价'移出首单；验证更值的 ΔP 口径**永久不对内对外声称**。"
（B/C/D 三路独立收敛到同一句——非巧合，但仍须五节实验产生一手证据。）

## 五、决定生死的下一个实验（取代 09"首单付费实验"）

**前置 Phase 0（≤3 周，不可跳过，无此不进入成交）**：
1. 主体：公司注册 + 人力资源服务许可证（或以正式分包协议与持牌主体建清晰角色边界），杜绝个人收款/借证代收。
2. 买方闸：须同时过 (i) 独立第三方性质（剔除 kunjie/@bole-hr.com 空壳/批量开通试点/自我人脉——无真实付款记录者不算）；(ii) 真 JD + 拍板人 + 境内可执行收款/开票路径。
3. 担保经属地执业律师审：事实型赔付、话术与合同逐字一致、保用窗 3-6 个月。

**唯一被允许的问句**："对经核验的真实境内买方，4 周内能否签下 ≥1 份真 JD + 成单费率 + 事实级担保的可执行订单，并推进 ≥2 名候选进该雇主真实面试？"
**硬指标**：只认定金/书面订单、真 JD、真实进面。**总时限 8 周**。
**Kill 线（任一即方向整体 kill）**：P0 无合法主体路径→资格 kill；4 周 0 个独立第三方真实买方出真 JD+拍板人→需求假 kill（**此判据取代 6685→2**）；背书猎头口头认可但 3 周无具体岗+联系人→渠道假 kill；绕登记直接录用/拒付款→归因假 kill。
**Pass 线**：≥1 真实成单按约收款 + 案例授权/复购信号。**即使 pass 也只证明该假设存活，仍不产生任何"验证溢价"证据**；"验证溢价/出海首单/出表提价"三个口径永久不进路线图。
