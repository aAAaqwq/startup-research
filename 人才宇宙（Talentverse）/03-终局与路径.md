# 人才宇宙（Talentverse）· 终局与路径

> 日期 2026-09-07。承接 10(结论)/09(首单实验)/04(合规)/06(第一性)。对象＝用户设想终局："国内第一家**去中心化 AI 招聘平台系统**——AI 去中心化交付结果：候选人持有可携带的能力证据/验证凭证，招聘方按协议接入，无平台收数据税。"本文件：① 现实先例校准 ② "去中心化"中国合法含义 ③ 4 阶段路径 ④ 对抗审查与放弃线。

## 〇、先下判断
"候选人自持可携带能力凭证 + 招聘方开放接入、不抽数据税"——海外有**真实制度雏形**，但中国有两条硬约束：**无强制互操作法律**＋**信任中心化在国家/平台**。故它是远期或有路径，不是今天的目标；当下唯一该做仍是 09 首单实验。

## 一、现实先例：真实 vs 炒作（联网核）

| 先例 | 判定 |
|---|---|
| 学信网/人社部证书核验 | **真实**，却是"可验证凭证"在中国唯一跑通的形态——信任中心化在国家，恰与"候选人自持"相反。你要么搭车、要么被它吞。 |
| 欧盟 EUDI Wallet / eIDAS 2.0 | **真制度**：2026 底各会员国须上线钱包、2027 受监管机构须接受；学历/职业资格以 W3C VC+OpenID4VC 签发，DC4EU 22 国试点。但靠"法令＋欧盟受信列表"＝**受监管中心化信任被凭证化，非无权威网络**；且只核验政府文件，不验"干活能力"。 |
| OpenBadges 3.0 / W3C VC / 1EdTech×HR Open(2025-06 结盟) | **标准真、招采端滞后**：85% 雇主自称技能型招聘，仅 ~0.14% 实单以技能凭证兑现——卡点在 ATS 与招聘者习惯，非技术。半真半炒。 |
| 印度 ONEST（Beckn/ONDC 同源） | **全球最接近你形态的真做**：开放协议撮合，Seeker/Provider 平台互操作、无中央撮合方，VC 钱包存证；试点(Blue Dot)到岗 2 天、成本降至 1/10。但靠国家 DPI＋社区治理、规模小——创业公司单干的样本尚无。 |
| Velocity Network 等区块链职业凭证 | 真存在，被存量背调巨头(ADP/Experian/Checkr)与联盟治理卡死("搭网+大家同意规则非小事"，SAP 参与方语)。偏炒。 |
| LinkedIn / Microsoft | LinkedIn **无真正便携档案**；2025 被 DMA 指定 gatekeeper 后才被迫开 Member Data Portability API，仍被批"合规表演"。Entra Verified ID 只给企业 IT 发雇员卡，不服务求职者自持。**→ 只有被监管巨头才放数据：自愿协议化商业史上不存在。** |
| 中国星火·链网 BID / RFC-013~15 / 星火通钱包 | 国家级 DID+VC 基建真实、活跃(~1亿标识符/日)，但招聘落点薄；2025-12"技术经理人数字身份认证"履历上链跨机构互认——真试点，但联盟链+协会发证＝信任仍中心化，无量化效果。 |
| PIPL §45 可携带权 | **立法有、细则无、实践≈0**（企业转移成功率 ~4.2%，生效后无支持判例）→ 中国无"强制互操作"，法律不会替你催生协议层。 |
| "先攒数据护城河、后协议化去中心化"（Stripe→Lattice 类） | a16z《数据护城河空头承诺》＋商业史一致：**跑通的协议(email/http/UPI/ONDC)要么第一天开放、要么国家主导；"先垄断再开放"基本是叙事**。服务→协议无创业公司成功大样本。 |

一句话：**凭证基建(VC/DID/钱包)全球已成熟；卡死它的一向是信任与习惯——谁发证、谁认，不是技术。**

## 二、"去中心化"在中国只能合法地指什么
不能是"个人数据上链"：链上公开＋不可篡改＝撞 PIPL 删除/更正权。合法语义收窄为三层：
1. **数据控制权**：授权范围、最小化、可撤销——靠单独同意实现，是义务不是差异化；
2. **可携带/互操作**：§45 无细则无义务 → 现实只能"主动结构化导出＋商业 API"，且**只对你自己的凭证开放；借协议壳搬 Boss/智联数据仍违法**（04 红线照旧）；
3. **凭证范式（发行-持有-出示）而非数据库**：链下存数据、链上只留 DID/哈希/撤销索引（星火 RFC 同款选择性披露）；就业需实名 → 中国 DID 实为"绑定实名的联盟信任"。

合规边界（叠加 04）：评估/推荐涉重大影响自动化决策或生成式 → **算法备案＋单独告知＋人工复核，去中心化不豁免**；收费"能力认证/发证"注意职业技能等级体系资质边界；反歧视举证责任倒置照旧；跨境出示走 PIPL §38/39 单独同意＋PIA。

## 三、路径：4 阶段（逐级可证伪）
晋级铁律沿用 06/09：**只有"与你经济利益解耦的外部方为此付费/采信"才可晋级**；否则停在原级，别为终局烧钱。

| 阶段 | 做什么 | 攒什么 | 晋级信号（可证伪） | 风险 |
|---|---|---|---|---|
| 1·AI验证型猎头(现在) | 对 bole 雇主/背书猎头交付"亲自技术验证的 AI 工程师"，20-30%成单+风险返还 | 验证方法论与判定记录；成单-人才匹配对；雇主信任 | 09 指标：≥1 成单或 ≥2 家续单（4 周死线） | 永远停在"人肉外包"，验证结果被雇主带走，攒不下数字资产 |
| 2·验证记录→可携带凭证 | 把阶段1产出结构化为候选人可携带凭证（先做"签名文档+唯一核验URL"，学信网/OpenBadges 同款；星火 BID 后置） | 签发与核验记录；"凭证离开你仍被采信"的案例 | **有一岗是别人撮合、只核验你的凭证就成交**；或候选人在非你渠道主动出示。证明验证资产独立于人 | 凭证价值＝你口碑，离开即废；LinkedIn/学信网一键复制 |
| 3·凭证协议/开放层 | 开源 schema+核验+发行规则；邀独立验证者（其他技术面试官/社区/教育机构/雇主内测）成 issuer，写"验什么/怎么撤/怎么投诉"rulebook | issuer 网络、互认、撤销申诉机制 | ≥1 个**与你无关的 issuer** 无补贴发证且被雇主采信；2-3 家 ATS/雇主接核验 API 而非找你人肉 | 三边冷启动空转；规则没人跟；标准化被国家/巨头吃掉 |
| 4·人才宇宙 | 撮合与验证解耦：任何接协议的渠道可撮合，能力真伪由凭证网络担保，无人抽数据税 | "验证层"声誉与回流数据(过没过/保用期结果→反哺评估) | "别人平台撮合的岗，用你的验证成交"成常态、凭证跨渠道多核验 | 平台梦真身＝网络效应+融资+十年，07 已判你一人 GTM 死穴 |

要点：**阶段 1-2 不需融资、复用现有服务，先做；阶段 3-4 是"阶段2 的核验数据显示凭证被外部采信"才兑现的或有路径**，现在别投入。

## 四、对抗审查：该不该追、何时放弃
**为何"国内第一家去中心化"比普通平台更难**：① 冷启动是发证/核验/持证三边空转，比双边更糟；② 中国信任中心化在学信网与背调，"没人信的开放凭证"教育成本≈无底洞；③ 无强制互操作法律，你逼不动任何平台接入；④ 大厂稀释——星火/学信网/DMA 下 LinkedIn 任一推出"统一职业凭证"，独立协议即被国家标准吸收；⑤ 它是"平台叙事"的高级改版，正是 06/10 反复识别过的自欺，只是这次更好听。

**判断（诚实）**：终局唯一值得保留的真核是"**验证记录的复用与可携带**"——应做成**阶段2 的产品**，不是 4 阶段旗帜。当"北极星叙事"可讲，当今天的目标会重蹈 06/10 的"用平台叙事骗自己"。放弃线（写死）：① 09 首单 4 周内死 → 终局随服务一起 kill/pivot；② 阶段2 证伪（凭证离开你口碑即归零）→ 老实做顶级技术猎头服务，也能活、不丢人；③ 阶段3 开放后无外人当 issuer、无核验 API 接入 → 协议梦死；④ 国家/巨头先出统一职业凭证标准 → **搭车当 issuer，别做独立协议，对抗必输**。
