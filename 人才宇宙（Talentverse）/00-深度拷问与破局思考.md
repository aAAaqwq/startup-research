## Q1. 会动到谁的蛋糕？

**直接侵犯者（危险）**：若继续"爬 Boss 数据"= 动 **Boss 直聘**的蛋糕 → 起诉史 + 2025 反不正当竞争法"数据专款"（已有判赔 23 万先例）+ 封号双风险。**红线：绝不爬/替代平台核心。**
**间接挑战者（机会）**：做"求职者侧 agent 帮候选人自己找机会"= 动的是**猎头/招聘平台靠信息差赚的蛋糕**（让候选人 agent 化绕过他们）——但这正是"颠覆招聘"的本意，且可借顶级猎头背书做"合作"而非"敌对"。
**已下场的巨头（你若做雇主侧/通用=直接撞）**：LinkedIn/Indeed/Mercor/OpenAI Jobs/Boss/智联。

## Q2. 存活几率？

| 路径 | 存活判断 |
|------|---------|
| 通用双向平台 | 极低：冷启动无解 + 巨头数据 + AI 压缩雇佣量 |
| **求职者侧窄楔子（AI 稀缺人才能力档案 + 出海/全球远程）** | **生存逻辑成立（方向性）**：AI 岗供需 3.2:1、唯一在扩大的岗位池；避开巨头主航道。（08审查修正）3.2:1 方向对、口径与精确值待一手验证，勿当精确值（06 H1；07 复核未能复现） |
| 大四+无市场能力 | 存活关键变量 = 能否拿到第一单 + 是否聚焦巨头不屑的窄位 |

诚实：AI 招聘行业失败率高，但"窄位 + 交付结果 + 信任 + 在场"是已被真实案例验证的活法。

## Q3. 破局路线？

1. 不依赖 Boss 数据（规避诉讼/被吸收）
2. 不撞巨头主航道（不做雇主侧通用撮合）
3. 从**求职者侧"AI 能力证据档案"**切：用户授权 GitHub/作品/项目+本地文件 → 结构化**能力证据**（非简历）→ 匹配全球远程 AI 岗
4. **本地优先 + 用户自持数据**（规避 Mercor 中心化泄露雷 + 大厂数据护城河） ⚠️(08审查修正) 与 06 H8 ❌ 矛盾：本地优先 = 平台无数据 = 无网络效应 = 变回工具；用户自持 = 可导出、零切换成本，不是差异化（07③）。本条属顶部注记已推翻的旧楔子
5. **按结果收费**（帮候选人拿到面试/offer 才收）→ 让买家获利，满足付费铁律 ⚠️(08审查修正) "付费铁律"是自造标签、至今无付款人（06 H6）；向候选人按 offer 收费结构性收不到（归因无解、必被绕单）——付费方已改为雇主/猎头（顶部注记、03/07），本条亦属旧楔子

## Q4. 最小验证可行性路线？

不用做平台。最小可验证产品：
```
一页工具：候选人贴 GitHub/项目链接 → AI 生成"能力证据报告" + 匹配 3-5 个远程 AI 岗
验证信号：20-30 个 AI 开发者（同学/社区/mentor 圈）里，
  多少人愿把简历换成能力报告？多少人靠它拿到面试？愿意付多少？
死线：2-3 周；≥1 个"靠它拿到面试/offer"的真实案例才继续
单边起步：只做求职者侧（供给侧），不做双边
```

## Q5. 是否已存在有人在做？

**是（主要在海外）**：Jobright（Indeed 投，52 万用户，$30/月）、LiftmyCV（自主求职）、Tsenta（YC，$100K MRR）、LinkedIn Job Match、OpenAI Jobs Platform（含求职者 agent）、Mercor（转数据供应商）。国内：智联"职悟空"未上线、Boss"直闪闪"免费内置。
**空档** = 中文 + AI 稀缺人才 + 出海/全球远程 + **证据型/本地优先** 组合 + 顶级猎头背书 + 按 offer 收费。

## Q6. 有无付费市场？

- **海外候选人付费真实**：Jobright $30/月 52 万用户；Tsenta $100K MRR；简历工具市场 $11亿→$48亿。
- 中国候选人付费弱（免费平台喂饱）→ **主打出海/全球远程**（海外付费）。 ⚠️(08审查修正) "海外候选人愿付费"是 06 H2 ❌ 假设：稀缺 AI 人才 75% 靠猎头/内推被动被找、巨头全免费，不为此付钱；唯一付费样本 Jobright 卖的是自动化省时间、不是档案报告。候选端付费勿当主现金流（顶部注记已改为雇主付费）
- 折中：向**猎头/企业**卖"AI 人才 sourcing + 验证"，按成单提成（你有顶级猎头背书 = 天然首批客户）。B 端付费 > C 端。

## Q7. 大厂是否下场？

**全面下场**：LinkedIn Hiring Assistant（年化 $450M）、Indeed 双 agent、OpenAI Jobs Platform、Boss DeepHire、智联职悟空、猎聘。
**但大厂的盲区**：都做"平台内"（靠自家数据 + 免费），**不做"用户自持 + 跨平台 + 本地优先"的独立资产**；也暂不做"中文 + 出海 AI 人才的证据型档案"。→ 这就是缝隙。

## Q8. 是否 codex/Claude 升级后便可取代？

**会取代的**：若产品只是"AI 帮你写简历/问答"——通用模型升级后免费就能做 → 被商品化吞掉（对抗审查的核心教训）。
**取代不了的**：
- 跨平台/跨模型的**用户数据主权 + 证据档案**（模型不拥有用户的历史项目/证据）
- 与真人猎头/企业的**信任 + 按结果交付闭环**
- **量化级验证/评估方法论**（不是简单生成，是"证明这人行不行"） ⚠️(08审查修正) 06 H5 🟡：Mercor 20 分钟视频面试、海纳 1500 万人次已在做，你的增量信号源尚无——"方法论"目前只是承诺、非已有资产
> 护城河不在"用模型生成"，在"拥有用户的证据数据 + 验证能力 + 结果责任"。

## Q9. 是否"交付结果+信任"？护城河有哪些？

**是**。方向 = 交付结果（候选人拿到面试/offer；企业找到能干活的人）+ 信任（验证/背书）。
**护城河候选（按可积累性排序）**：
1. **用户自持的"能力证据数据"**——跨平台，模型/平台拿不走（最硬）
2. **验证/评估方法论**——agent 时代的能力背调（稀缺）
3. **猎头背书 + 按 offer 成功收费**的信任链
4. **本地优先 + 合规**（规避中心化数据泄露雷，差异化）
5. 早期在 AI 稀缺人才细分里的**人才密度/口碑**
> 诚实：真护城河要时间攒（数据+信任）；初期护城河 ≈ 猎头背书 + 你自己是这个社区的成员 + 交付质量。
>
> ⚠️ (08审查修正) 顶部注记已推翻 Q9 原结论，本节排序仍是旧稿：把"用户自持数据 / 本地优先"排第 1、4 名与 06 H8 ❌ 冲突（可导出=零切换成本、攒不下撮合资产，07③）。真资产应定义为"验证记录 / 口碑 / 撮合结果"，并把"雇主/猎头信任链 + 按成单交付责任"前移。

## 一页总结（拷问答案浓缩）
- **动谁的蛋糕**：别动 Boss（红线）；动的是猎头/平台的信息差，用合作而非敌对
- **存活率**：窄位求职者侧可行，通用平台几乎必死
- **破局**：AI 稀缺人才证据档案 + 用户自持 + 按结果收费 + 出海
- **最小验证**：一页工具，2-3 周，拿 1 个"靠它拿到 offer"案例
- **已有人做**：有（海外），空档在中文+AI人才+出海+证据型
- **付费市场**：海外真实；中国弱 → 出海 + B 端猎头成单提成
- **大厂**：全下场，但都做平台内免费，不做用户自持独立资产
- **模型升级**：会商品化"生成"层，取代不了"数据主权+验证+信任"
- **护城河**：用户证据数据 > 验证方法论 > 猎头信任链 > 合规本地优先 > 细分口碑
